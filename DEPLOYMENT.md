# Deployment preparation

## Vercel + PostgreSQL

This retains React/Vite for static pages and Express/Node for APIs. The included Vercel configuration routes `/api/*` and `/fonts/*` to `api/index.js`, and `/admin` to the frontend. Database state is external; no writable function disk is used.

1. Run the project locally with Node 24. Run `npm install`, `npm run setup-fonts`, `npm run setup-admin`, `npm test`, and `npm run build`.
2. Create a PostgreSQL database (Neon or another compatible provider). Use its **pooled TLS connection string** as `DATABASE_URL`; do not disable TLS certificate validation. Tables initialize automatically; the database role needs permission to create the application's tables/index.
3. Import the project folder into Vercel from your private repository, or deploy the folder with Vercel CLI. Choose the Vite framework, Node 24 runtime, `npm run build`, output `dist`. The project root must contain `package.json`, `api/`, and `vercel.json`.
4. Set these server environment variables in the host dashboard, never as VITE_ variables:
   - `DATABASE_URL`: pooled PostgreSQL URL.
   - `ADMIN_PASSWORD_HASH`: copy the generated value from your local `.env`.
   - `SESSION_SECRET`: copy the generated value from `.env` (at least 32 characters).
   - `AI_CONFIG_ENCRYPTION_KEY`: 64 hex characters generated by setup-admin or setup-ai-encryption. Required for dashboard API-key storage; keep stable across redeployments.
   - `GEMINI_API_KEY`: optional environment fallback; alternatively save the key from the admin dashboard after deployment.
   - `GEMINI_MODEL`: e.g. `gemini-2.5-flash`, or a supported vision model on your account.
   - `APP_ORIGIN`: your exact public origin, e.g. `https://your-project.vercel.app` (no trailing slash).
   - `NODE_ENV=production`.
   - Optional `AI_HOURLY_LIMIT=100`: global successful/attempted AI request budget per fixed hour, in addition to the per-browser limit.
5. Provide `fonts/times.ttf` and `fonts/timesbd.ttf` in the deployment bundle using appropriately licensed fonts. `.gitignore` excludes them by default; if your licence permits hosting, explicitly include them in your private deployment source. The function `includeFiles` includes them when present. Do not commit `.env` or database files. Without fonts, the website and other tools work but cover exports return a setup message.
6. Deploy, open `/admin` and sign in. Update text/logos, export one cover, merge PDFs, export a routine, and check the counts. Re-deploy once and confirm settings remain.
7. For preview deployments, use separate preview credentials/database or restrict access. Never connect public previews to your production admin/database configuration by accident. Vercel's own deployment hostname is allowed automatically; configure APP_ORIGIN for your custom domain.

The AI key stays server-side. Dashboard keys are encrypted in PostgreSQL. Never expose AI_CONFIG_ENCRYPTION_KEY to frontend variables; back it up separately. Password resets preserve the encryption key generated in your local .env. Public AI access has database-backed per-browser and global limits, but is not a paid-user system. Adjust your provider quota and the application budget for expected traffic. Password resets use `npm run setup-admin`; update both generated values on the host and redeploy, which invalidates existing session hashes.

**Not yet verified:** an actual deployment to your Vercel account, production PostgreSQL connectivity, or live Gemini extraction. These require your external accounts/secrets. No hosting accounts have been created and nothing has been published.

## Alternative: a conventional Node web service

Use a Node host such as a VPS or a service that runs a persistent Express process. Run `npm ci && npm run build` during build and `npm start` to serve. Set `HOST=0.0.0.0`, use the platform's PORT, configure `APP_ORIGIN` and `NODE_ENV=production`, and put HTTPS in front of the app. Use DATABASE_URL, or mount a persistent disk at DATA_DIR. Without a persistent disk or external database, updates will erase local SQLite state. Configure Express trust proxy to match your reverse proxy before trusting forwarded client IPs; the Vercel setting is already included.
